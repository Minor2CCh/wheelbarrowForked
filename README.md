# wheelbarrow

_A fork of asasinmode's [“Wheelbarrow”](https://github.com/asasinmode/wheelbarrow) that is compatible with NeoForge, with a few original elements added._

## Additional Features

・Even if I remove it after applying the honeycomb pattern, the effect no longer wears off.<br/>
・As a result, be able to wax the Wheelbarrow using the Craft Recipe.<br/>
・Added two new settings (immuneWallDamage, placeableInWater).<br/>
・If `immuneWallDamage` is set to `true`, entities riding in a wheelbarrow will no longer take in-wall damage.<br/>
・If `placeableInWater` is set to `true`, can place the Wheelbarrow underwater.<br/>
・Requests to the Cloth Config API will become optional.<br/>
